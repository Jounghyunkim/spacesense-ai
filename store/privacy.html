한국어

SpaceSense AI(이하 "앱")는 JohnnyStudio가 제공하는 Windows용 디스크 공간 분석·정리 도구입니다.

수집하는 정보

개발자는 어떠한 개인정보도 수집하거나 보관하지 않습니다. 앱에는 계정, 광고, 사용 통계(텔레메트리) 수집 기능이 없으며 개발자가 운영하는 서버로 전송되는 데이터가 없습니다.

PC 안에서만 처리되는 정보

  • 스캔 결과: 폴더·파일의 이름, 경로, 크기는 화면 표시를 위해 메모리에서만 처리되며 앱을 종료하면 사라집니다.
  • 설정: 선택한 AI 제공자, 모델 이름, API 키가 사용자 PC에 저장됩니다. API 키는 Windows DPAPI로 암호화되어 현재 Windows 사용자 계정으로만 복호화할 수 있습니다.

제3자에게 전송되는 정보

사용자가 AI 분석이나 채팅을 직접 실행한 경우에만, 다음 정보가 사용자가 설정에서 선택한 AI 제공자에게 전송됩니다.

  • 스캔 결과 요약(용량이 큰 폴더·파일의 이름, 경로, 크기, 수정 시각, 확장자별 용량 통계)
  • 사용자가 입력한 채팅 메시지

경로에는 Windows 사용자 이름이나 폴더·파일 이름이 포함될 수 있습니다. 제공자별 전송 대상은 다음과 같습니다.

  • Ollama: 사용자가 지정한 주소(기본값은 사용자 PC의 localhost)로 전송되며, 기본 설정에서는 데이터가 PC를 떠나지 않습니다.
  • OpenAI 호환 API: 사용자가 지정한 서버로 전송되며 해당 서비스의 개인정보처리방침이 적용됩니다.
  • Anthropic Claude: Anthropic API로 전송되며 Anthropic의 개인정보처리방침이 적용됩니다.

AI 기능을 사용하지 않으면 앱은 외부로 어떠한 데이터도 전송하지 않습니다.

데이터 삭제

앱을 제거하면 저장된 설정이 함께 삭제됩니다. AI 제공자에게 전송된 데이터의 보관과 삭제는 해당 제공자의 정책을 따릅니다.

아동

앱은 아동을 대상으로 하지 않으며 아동의 개인정보를 수집하지 않습니다.

English

SpaceSense AI ("the app") is a disk space analyzer and cleanup tool for Windows published by JohnnyStudio.

Information we collect

The developer does not collect or store any personal information. The app has no accounts, no ads and no telemetry, and it sends no data to servers operated by the developer.

Information processed only on your PC

  • Scan results: file and folder names, paths and sizes are held in memory for display and are discarded when the app closes.
  • Settings: your chosen AI provider, model name and API keys are stored on your PC. API keys are encrypted with Windows DPAPI and can only be decrypted by your Windows user account.

Information sent to third parties

Only when you start an AI analysis or chat yourself, the following is sent to the AI provider you selected in settings:

  • a summary of the scan (names, paths, sizes and modified times of the largest folders and files, and size statistics per file extension)
  • the chat messages you type

Paths may contain your Windows user name and file or folder names. Depending on the provider:

  • Ollama: sent to the address you configure (by default localhost on your own PC), so with the default setting data does not leave your PC.
  • OpenAI-compatible API: sent to the server you configure and subject to that service's privacy policy.
  • Anthropic Claude: sent to the Anthropic API and subject to Anthropic's privacy policy.

If you do not use the AI features, the app transmits no data.

Deleting data

Uninstalling the app removes its stored settings. Retention and deletion of data sent to an AI provider are governed by that provider's policies.

Children

The app is not directed at children and does not collect children's personal information.
